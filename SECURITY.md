# Security policy

## Supported versions

Only the latest release of Trayload gets fixes. Trayload updates itself, so most people are on it already.

## Reporting a problem

Please **do not** open a public issue for a security problem.

Use **Security > Report a vulnerability** on this repository's GitHub page to send a private report. Include what you found, how to reproduce it, and which version you used.

You can expect an answer within about a week. This is a small volunteer project, so please be patient. Once a fix is released, you are welcome to be credited in the release notes.

## What counts

- Trayload downloading from a source other than the pinned official ones, or running something it should not.
- Ways to make Trayload read, change or delete files outside its own folders and the games you added.
- Problems in the update mechanism.

Trayload sends no telemetry and has no account system or server. The installer is not code-signed, so Windows may show a SmartScreen warning. That is known and not a vulnerability.

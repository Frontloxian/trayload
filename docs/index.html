Trayload

One place to install, update and launch your emulators on Windows. Free, open source, no telemetry.

Download the latest version

  • Official sources only. Emulators are downloaded from each project's own release page, never from a mirror.
  • A clean library. Drop games onto the window. Trayload recognises the console, copies them into a folder per console, and fetches covers.
  • A checklist for the awkward bits. The Setup tab shows which BIOS or firmware files each console needs and checks whether you have them.
  • Stays up to date. "Update ready" badges, optional automatic updates, and a News tab for emulator releases.

Trayload does not provide, host or link game ROMs, BIOS files, firmware or encryption keys. You supply those yourself from games and consoles you own.

FAQ

Does Trayload include games, BIOS files or keys?

No. Trayload does not provide, host or link ROMs, BIOS files, firmware or keys, and it will never ask you to share them. Use files dumped from games and consoles you own.

Is it free? What is the license?

Yes. Trayload is free and open source under the GPL-3.0 license. The built-in music and the logo are under CC BY-NC 4.0.

Does it collect any data?

No telemetry, no analytics, no accounts and no crash reporting. Every network request Trayload makes is listed in the privacy page.

Why does Windows warn me when I install it?

The installer is not code-signed yet (a signing certificate costs money), so SmartScreen shows a warning for unknown publishers. Choose More info, then Run anyway. Releases are built by GitHub from the public source code.

Where does Trayload get emulators?

Only from each emulator's official release page (GitHub, or the project's own site). Downloads from any other site are refused.

Which consoles are supported?

See Systems and BIOS. It lists every console, its emulator and what it needs.

What happened to RetroArch?

Trayload used to run some older consoles through RetroArch. It was dropped because BIOS setup was awkward and individual emulators are easier to manage. Sega consoles moved to their own emulators (ares and Ymir). The other consoles are planned to come back through community addons. Games you already added stay in your library.

Does Trayload copy my games?

Games you drag onto the window are copied into the games folder, one folder per console, and your originals are left alone. Folders you add with Add folder are scanned in place. Existing games can be brought into the games folder from Settings, as a copy or a move.

What does 'Delete permanently' do?

It removes every trace of a game from Trayload: the entry, cover, play time, favorite and collections. Files in Trayload's games folder go to the Recycle Bin (games that were moved in go back to where they came from). Files anywhere else are never touched.

Can I use an emulator that is not on the list?

Not yet. Addons that add emulators and themes are planned for a later version.

Does it work on Mac or Linux?

Not at the moment. Trayload is Windows-only.

How do I back up my saves?

In Settings, use the backup section to copy saves, save states and emulator settings to a USB drive or any folder you pick.

How do I uninstall it?

Use Windows "Installed apps". Trayload's data (library, covers, emulators, logs) is in %LOCALAPPDATA%\com.loxianthepeak.trayload and your games folder is under Documents\Trayload. Neither is deleted automatically, so you can remove them by hand if you want everything gone.

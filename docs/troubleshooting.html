Troubleshooting

Windows blocks or warns about the installer

That is SmartScreen, because the installer is not code-signed. Choose More info, then Run anyway. If your antivirus quarantines an emulator after it is installed, add Trayload's emulator folder (%LOCALAPPDATA%\com.loxianthepeak.trayload\emulators) to its exclusions. Emulators are sometimes flagged wrongly.

An emulator will not install, or says no matching download

Emulators sometimes rename their download files. Open Settings, then Online updates and click Check now, because a fixed list may already be available. If it still fails, open an issue with the name of the emulator and the message you see.

A game does not start

1) Check the Setup checklist for missing BIOS or firmware. 2) Make sure the emulator is installed (Emulators tab). 3) Open Settings, then Open log folder to see what happened. 4) Try the game directly in the emulator to tell whether the problem is the game file or Trayload.

The game page says "no emulator installed"

Trayload no longer has an emulator for that console (for example PC Engine or Atari, which RetroArch used to cover). The game stays in your library. Community addons are planned to cover these consoles.

Trayload asks which console a file is for

Some file types (like .iso, .bin or .chd) are used by several consoles and cannot always be recognised. Pick the console once and Trayload remembers. A folder named after the console (for example PlayStation) also helps it decide.

A game shows as missing

Trayload cannot find the file where it was last seen, for example because a drive is disconnected or the file moved. Reconnect the drive or put the file back, then press Rescan.

Copying games stops with a space error

Trayload checks free disk space before it copies. Free some space, or change the games folder to a drive with more room in Settings, then drop the games again. Anything already copied is kept, and identical files are skipped.

A cover is missing or wrong

Covers come from libretro-thumbnails, and from SteamGridDB if you add a free key in Settings. Games with unusual names may not match. You can pick a different cover on the game's page.

There is no music

Check that Play music is ticked in Settings and the volume is up. Music pauses automatically while a game is running.

I still have an old RetroArch folder

Older versions installed RetroArch. Trayload offers to back up its saves and BIOS files and asks before deleting it. You can do it any time under Settings, then Old RetroArch folder.

Something else is wrong

Open Settings, then Open log folder, and look at the newest log. Then open an issue with your Trayload version and what happened. Please do not attach ROMs, BIOS files or keys. Check the log for private file paths before pasting it.

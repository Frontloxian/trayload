Systems and BIOS

Which emulator Trayload uses for each console, and the files each one needs.

Trayload does not provide or link BIOS files, firmware or keys. Where one is needed, dump it from your own console. The Setup checklist in the app checks for these files and shows exactly where to put them.

NES / FamicomMesen 2

Nintendo NES and Famicom games run without extra files.

FileNotes
Famicom Disk System BIOS (disksys.rom)OptionalSize: 8 KB Optional. Only for Famicom Disk System games. Put it in the Firmware folder.

File types: .nes .fds .unf

Super NintendoMesen 2

Most Super Nintendo games run without extra files.

FileNotes
Extra-chip firmware (dsp1.rom, st010.rom and similar)OptionalOptional. Only a few games with special chips ask for these.

File types: .sfc .smc .fig

Game Boy / ColormGBA

Game Boy and Game Boy Color games run without a BIOS. A real boot ROM is optional.

File types: .gb .gbc

Game Boy AdvancemGBA

mGBA has a built-in replacement BIOS, so games run without one. A real GBA BIOS is optional.

FileNotes
GBA BIOS (gba_bios.bin)OptionalSize: 16 KB Optional. Pick it in mGBA under Tools, Settings, BIOS.

File types: .gba

Nintendo 64RMG

Nintendo 64 games run without extra files.

File types: .z64 .n64 .v64

Nintendo DSmelonDS

melonDS has a built-in replacement BIOS and firmware, so games run without these. Real files are optional and improve compatibility.

FileNotes
DS ARM7 BIOS (bios7.bin)OptionalSize: 16 KB
DS ARM9 BIOS (bios9.bin)OptionalSize: 4 KB
DS firmware (firmware.bin)OptionalSize: 128 KB or 256 KB or 512 KB Set the paths in melonDS under Config, Emu settings, DS-mode.

File types: .nds .dsi

Nintendo 3DSAzahar

Most 3DS games run without extra files.

FileNotes
Encrypted-game keys (aes_keys.txt)OptionalOptional. Only for games that are still encrypted. Put it in the sysdata folder.

File types: .3ds .cci .cxi

GameCubeDolphin

GameCube games run without any extra files.

FileNotes
GameCube BIOS (IPL.bin)OptionalOptional. Only needed to see the GameCube boot logo. Put it in a USA, EUR or JAP folder inside this one.

File types: .iso .gcm .rvz .gcz

WiiDolphin

Wii games run without extra files.

File types: .iso .wbfs .rvz .wad

Wii UCemu

Cemu needs the Wii U keys file to open encrypted game dumps. Decrypted dumps don't need it.

FileNotes
Wii U keys (keys.txt)OptionalOptional if your games are decrypted. Use keys from your own console. Put it next to Cemu.exe.

File types: .wud .wux .wua .rpx

Nintendo SwitchEden

Eden needs prod.keys, and many games also need firmware, both from your own Switch. Trayload doesn't provide or link them.

FileNotes
Switch keys (prod.keys)RequiredGoes in the keys folder inside this one.
Switch firmwareOptionalNeeded by many games. Install it from inside Eden (Tools, then Install Firmware).

Needs prod.keys and firmware dumped from your own Switch. Trayload never provides or links them. Eden is downloaded from its official release server (git.eden-emu.dev, with files from stable.eden-emu.dev).

File types: .nsp .xci

PlayStationDuckStation

DuckStation needs a PlayStation BIOS file from your own console. One file is enough.

FileNotes
PlayStation BIOSRequiredSize: 512 KB A 512 KB .bin file (for example scph5501.bin). Pick one that matches your games' region.

File types: .bin .cue .chd .pbp

PlayStation 2PCSX2

PCSX2 needs a PlayStation 2 BIOS from your own console.

FileNotes
PlayStation 2 BIOSRequiredSize: 4 MB A 4 MB .bin file. Pick one that matches your games' region.

File types: .iso .chd .cso

PlayStation 3RPCS3

RPCS3 needs the PS3 system software from your own console, installed from RPCS3 under File, Install Firmware.

FileNotes
PS3 system software (installed)RequiredFound after the firmware is installed. This check is a best guess.

File types: .iso .pkg

PSPPPSSPP

PSP games run without extra files.

File types: .iso .cso .pbp

PS VitaVita3K

Vita3K needs the PS Vita firmware and font package from your own console, installed from Vita3K under File. Install each game once in Vita3K (File, Install .vpk). After that, Play starts it by its Title ID.

FileNotes
PS Vita firmware (installed)OptionalFound after the firmware is installed. This check is a best guess, so it never blocks anything.

File types: .vpk

DreamcastFlycast

Flycast has a built-in replacement BIOS, so these files are optional. Real ones can improve compatibility.

FileNotes
Dreamcast boot ROM (dc_boot.bin)OptionalSize: 2 MB
Dreamcast flash (dc_flash.bin)OptionalSize: 128 KB

File types: .gdi .cdi .chd

Original Xboxxemu

xemu needs three files from your own original Xbox: the boot ROM, the BIOS and a hard drive image. Set their paths in xemu under System.

FileNotes
MCPX boot ROMRequiredSize: 512 bytes
Xbox BIOS (flash ROM)RequiredSize: 256 KB or 512 KB or 1 MB
Hard drive imageRequired

File types: .iso

ArcadeMAME

MAME needs a ROM set (a .zip per game) that matches its version. Trayload doesn't provide or link them.

FileNotes
Arcade ROM sets (.zip files)OptionalOptional here. Put them in the roms folder.

File types: .zip

Not supported right now

Trayload no longer ships an emulator for: PC Engine / TurboGrafx-16, Atari 2600, Atari 5200, Atari 7800, Atari Lynx, Atari Jaguar, Neo Geo Pocket, WonderSwan, Virtual Boy, Pokemon Mini, ColecoVision, Intellivision, Vectrex, MSX, 3DO, PC-FX. Games you already added for these stay in your library, marked "no emulator installed". Community addons are planned to cover them later.

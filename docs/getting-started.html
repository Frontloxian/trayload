Getting started

From install to your first game.

1. Install Trayload

Download the installer from the latest release and run it. It installs for your user account only, so it does not ask for administrator rights.

Windows may show a "Windows protected your PC" (SmartScreen) message, because the installer is not code-signed yet. Choose More info, then Run anyway. The code is open source, and every release is built on GitHub from the public source.

2. Install an emulator

  1. Open the Emulators tab.
  2. Click Install next to the emulator for your console, or Install all… to pick several at once. You see the download sizes first.
  3. Trayload downloads it from the emulator's official page and sets it up in its own folder. Nothing else on your PC is changed.

3. Check what the console needs

Open the Setup checklist tab. Some consoles need files from your own console, such as a BIOS or firmware. The checklist shows what is missing, and Open folder takes you to the exact place to put each file. See Systems and BIOS for the full list.

4. Add your games

  • Drag game files or folders onto the Trayload window. Trayload recognises the console and copies each game into Documents\Trayload\Games\<console>. Your originals are not changed. Games with several files (such as a .cue with .bin files) are kept together, and several discs of one game become one entry.
  • If Trayload cannot tell which console a file is for, it asks you.
  • Add folder in the Library scans a folder where it is, without copying. Good for a large collection you already keep somewhere.
  • You can change the games folder, and bring games you added earlier into it, under Settings.

5. Play

Click a game, then Play. Trayload starts the right emulator, tracks play time, and lists the game under Recently played. Use Favorites and Collections to organise, and the game's page for per-game launch options and notes.

Handy things

  • Press ? for the keyboard shortcuts. A controller can move around the app too.
  • Settings has covers (optional SteamGridDB key), music, backups to a USB drive or any folder, online updates and the games folder.
  • Trayload updates itself: an update banner appears when a new version is out, with release notes.
